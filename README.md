# 🏝️ Pulau Komunitas 3D

Game komunitas 3D single-file (Three.js) — jalan-jalan di pulau, mancing, manjat kelapa, masak, kemah, nambang kristal, dan main bareng teman lewat multiplayer P2P.

## Cara main

Buka `index.html` di browser (atau lewat GitHub Pages). Tidak perlu install apa pun.

- **WASD / Dpad HP** — jalan
- **Spasi / tombol Lompat** — lompat
- **E / tombol aksi** — mancing, manjat, masuk kemah, nambang
- **Geser layar / drag mouse** — putar kamera
- **🌐 Main Bareng** — buat room, bagikan kode 6 huruf ke teman

## Fitur

- 🎣 Mancing (termasuk spot ikan emas) • 🌴 Panjat kelapa • 🍳 Resep masakan
- ⛺ Kemah (bangun, istirahat, bongkar) • ⛏️ Tambang Kristal • 🦀 Tangkap kepiting
- 🌦️ Siang/malam & cuaca • 📋 Misi harian • 🏪 Toko Pak Kumis
- 🆘 Makanan darurat (+50 energi, 1x per 10 menit) • 💾 Save otomatis (localStorage)
